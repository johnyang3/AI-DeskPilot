# DeskPilot 桌面管家

[English](README.md) | **简体中文**

**中文使用说明｜当前版本：0.1.0｜适用系统：Windows 10/11 x64**

DeskPilot 是一款 Windows 小窗口桌面工具，提供批量解压、可撤销的桌面整理、清理候选扫描、AI 辅助管理电脑，以及基于 GitHub 发布页的自动更新功能。

## 主要功能

- **批量解压**：支持 ZIP、7Z、RAR、TAR、GZ/TGZ。每个压缩包解压到独立目录，不覆盖已有文件，并检查路径穿越风险。
- **桌面整理**：只整理当前用户桌面顶层的普通文件，按文档、图片、视频、音频、压缩包和其他文件分类。默认跳过快捷方式、程序、脚本、隐藏文件、系统文件和受保护路径。
- **撤销整理**：每次整理都会在本机保存记录，可以撤销最近一次桌面整理。
- **清理候选扫描**：扫描超过 7 天未修改的当前用户临时项目、符合自定义规则的已安装程序，以及 Chrome、Edge 和部分 360 浏览器的扩展目录。
- **360 相关项目检测**：根据程序名称、发布者、扩展清单和域名规则列出候选，是否保留由用户决定。
- **文件保护**：受保护文件、受保护目录及其子项不会被清理功能回收，桌面整理也会自动跳过。
- **AI 辅助管理**：接入 OpenAI 兼容接口，通过白名单工具查看系统信息、列出桌面文件、扫描清理候选，以及在确认后整理、解压、回收文件或启动程序卸载器。
- **自动更新**：检查 GitHub 最新正式发布，下载后核验 SHA-256，确认更新后备份旧程序、替换文件并重启。
- **界面语言**：自动跟随 Windows 显示语言。首版内置简体中文和英文，其他语言暂时使用英文。

> 清理候选只表示“符合人工复核规则”，不代表该程序或扩展一定是恶意软件。软件不会仅凭扫描结果自动卸载程序或删除文件。

## 下载与启动

1. 从 GitHub 发布页下载 `DeskPilot-win-x64.zip`。
2. 将压缩包完整解压到一个普通文件夹。
3. 双击运行 `DeskPilot.exe`。

发布包是 Windows x64 自包含单文件程序，不需要另外安装 .NET 运行时。

首次运行时，Windows SmartScreen 可能显示提示。本项目目前没有购买代码签名证书，请只使用本项目发布页提供的程序包，并确认其 SHA-256 与 `DeskPilot-win-x64.zip.sha256` 一致。

## 使用说明

### 一、批量解压

1. 打开“批量解压”页。
2. 点击“添加压缩包”，可一次选择多个文件。
3. 点击“选择输出目录”。
4. 点击“开始解压”，确认后执行。

每个压缩包会解压到独立的同名子目录。如果目录已经存在，程序会创建带序号的新目录，不覆盖原目录中的文件。

### 二、桌面整理

1. 打开“桌面整理”页。
2. 点击“预览整理”，先查看拟移动的文件和目标位置。
3. 点击“执行整理”，确认后开始移动。
4. 如需恢复，点击“撤销上次整理”。

整理后的文件默认放在桌面的 `DeskPilot整理` 文件夹中。程序只处理文件，不移动桌面上的文件夹。

### 三、清理助手

1. 打开“清理助手”页，点击“扫描清理候选”。
2. 根据名称、类型、路径和匹配原因人工复核。
3. 勾选需要处理的候选，点击“移除/卸载所选”。
4. 阅读确认提示后再决定是否继续。

普通文件和扩展目录会进入 Windows 回收站；已安装程序会启动其注册的官方卸载入口。卸载第三方浏览器扩展前，请先关闭对应浏览器。程序不会强制结束浏览器或其他软件进程。

### 四、AI 管理

1. 打开“AI 管理”页。
2. 填写 OpenAI 兼容的聊天补全接口，例如：

   `https://api.openai.com/v1/chat/completions`

3. 填写服务商支持的模型名和 API 密钥。
4. 点击“加密保存设置”。密钥使用 Windows DPAPI 按当前用户加密，不以明文保存。
5. 在输入框填写要求，例如“列出桌面文件”或“扫描 360 相关扩展候选”。按“发送”或 Ctrl+Enter 提交。

AI 只能使用程序提供的白名单工具，没有任意命令行或 Shell 执行权限。只读操作可以自动执行；解压、整理、回收文件和卸载程序都会弹出本机确认框，取消即不执行。

API 请求会把当前对话以及工具返回的必要信息发送给你配置的服务商。请勿在对话中输入密码、身份证号或其他敏感信息。

### 五、设置与更新

- **保护路径**：每行填写一个文件或目录的完整路径，点击“保存保护规则”。
- **检查更新**：点击“检查并安装更新”。发现新版本后，程序会先请求确认，再下载、校验并安装。
- **打开仓库**：点击“打开 GitHub 仓库”查看源码和发布记录。

## 自定义清理候选规则

首次扫描后，可以编辑：

`%APPDATA%\DeskPilot\cleanup-rules.json`

默认内容如下：

```json
{
  "ProgramKeywords": ["360", "2345", "hao123"],
  "ExtensionKeywords": ["360.cn", "360safe.com", "so.com", "haosou.com", "360浏览器", "360安全"]
}
```

- `ProgramKeywords`：匹配已安装程序的名称或发布者。
- `ExtensionKeywords`：匹配浏览器扩展清单中的相关文本或域名。

这些规则只是人工复核条件，不是病毒特征库。扩展清单中的 `__MSG_*__` 国际化名称可能无法完整解析，扫描以清单原文和可见域名为准。

## 本地构建

### 环境要求

- Windows 10/11 x64
- .NET 8 SDK

### 运行测试

```powershell
dotnet test tests/DeskPilot.Tests/DeskPilot.Tests.csproj -c Release
```

### 发布 Windows x64 程序

```powershell
dotnet publish src/DeskPilot/DeskPilot.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o artifacts/win-x64
```

构建结果位于 `artifacts/win-x64`。

## 自动发布与更新

推送到 `main` 分支，或手动运行 `build-and-release` 工作流，GitHub Actions 会自动执行测试、构建程序、生成压缩包和 SHA-256 文件，并更新 `v0.1.0` 发布记录。

升级版本时，应同时修改：

1. `src/DeskPilot/DeskPilot.csproj` 中的 `<Version>`。
2. `.github/workflows/release.yml` 中的 `tag_name` 和 `name`。
3. 推送对应的新版本标签。

## 隐私与本地数据

设置、加密密钥、整理历史和清理候选规则保存在：

`%APPDATA%\DeskPilot`

程序不包含遥测。GitHub 更新检查不会携带 API 密钥；AI 请求仅发送到你配置的接口。

## 当前限制

- 首版仅提供 Windows x64 版本。
- 暂不处理分卷压缩包。
- 暂不扫描 Firefox 扩展。
- 不自动解除第三方软件的自保护。
- 没有代码签名证书，首次运行可能出现 SmartScreen 提示。
- 非中英文 Windows 环境暂时回退为英文界面。
